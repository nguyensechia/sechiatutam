# Thư mục private/

Đặt file PDF sản phẩm thật vào đây với tên: `so-tay-xay-kenh-viral-ebook.pdf`

File PDF **không được commit lên Git** (xem `.gitignore`) vì repo này là public trên GitHub — nếu đưa
file thật lên, ai cũng tải free được. Khi deploy lên Hostinger, upload file PDF trực tiếp vào thư mục
`private/` trên server qua File Manager/SFTP, không qua git.
